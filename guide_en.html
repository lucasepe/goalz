CSV input file structure

This page explains required fields of the CSV input file.

Required fields in teams.csv

  • team - team name.
  • HomeXGF - expected goals scored at home.
  • AwayXGF - expected goals scored away.
  • HomeXGA - expected goals conceded at home.
  • AwayXGA - expected goals conceded away.
  • HomePlayed - home matches played.
  • AwayPlayed - away matches played.

Minimal CSV example

team,HomeXGF,AwayXGF,HomeXGA,AwayXGA,HomePlayed,AwayPlayed
Inter,1.72,1.08,0.98,1.31,18,18
Milan,1.54,0.99,1.11,1.22,18,18
Napoli,1.49,1.02,1.05,1.18,18,18
